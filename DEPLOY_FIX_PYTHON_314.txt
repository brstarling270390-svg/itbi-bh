QUANTO VALE BH — CORREÇÃO DE DEPLOY NO STREAMLIT COMMUNITY CLOUD
Data: 11/07/2026

CAUSA IDENTIFICADA
O app publicado está sendo provisionado pelo Streamlit Community Cloud com Python 3.14.6.
A versão auditada anterior fixava pandas==2.2.3.

O pandas 2.2.3 foi lançado antes do suporte a CPython 3.14 e não publica wheel cp314 no PyPI.
No ambiente Python 3.14 do Streamlit, o uv resolve as dependências, mas pode precisar tentar construir
essa versão antiga do pandas a partir do código-fonte, o que explica o provisionamento parado em
"Resolved 48 packages" durante "Processing dependencies".

CORREÇÃO
requirements.txt alterado de:
  pandas==2.2.3
para:
  pandas==2.3.3

O pandas 2.3.3 possui wheels oficiais para CPython 3.14 no PyPI.
As demais dependências principais fixadas permanecem:
  streamlit==1.59.1
  duckdb==1.5.4
  requests==2.32.5
  plotly==6.5.2
  openpyxl==3.1.5

VALIDAÇÕES
- resolução do conjunto de 48 pacotes com uv para alvo Python 3.14/Linux: aprovada;
- instalação isolada do requirements.txt corrigido: aprovada;
- versões efetivamente instaladas no teste isolado:
  pandas 2.3.3
  streamlit 1.59.1
  duckdb 1.5.4
  requests 2.32.5
  plotly 6.5.2
  openpyxl 3.1.5
- 13 testes automatizados do aplicativo com pandas 2.3.3: aprovados.

OBSERVAÇÃO
Esta correção não altera a metodologia, a interface nem os cálculos do aplicativo.
Altera apenas a compatibilidade do ambiente de deploy com o Python 3.14 usado pelo Streamlit Cloud.
