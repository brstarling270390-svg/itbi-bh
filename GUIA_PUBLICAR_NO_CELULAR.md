# Publicar o ITBI BH para uso no celular

## Resultado esperado

Após a publicação, o aplicativo terá um endereço como:

`https://itbi-bh.streamlit.app`

Ele poderá ser aberto no Safari ou Chrome. No iPhone, use **Compartilhar > Adicionar à Tela de Início** para criar um ícone semelhante ao de um aplicativo instalado.

## Publicação no Streamlit Community Cloud

1. Crie uma conta no GitHub.
2. No GitHub, crie um repositório novo, por exemplo `itbi-bh`.
3. Envie todos os arquivos desta pasta para o repositório.
4. Entre no Streamlit Community Cloud com a conta do GitHub.
5. Escolha a opção de criar um aplicativo.
6. Selecione o repositório `itbi-bh`, a branch principal e o arquivo `app.py`.
7. Escolha um endereço disponível e conclua a implantação.
8. Na primeira abertura, toque em **Preparar base recente**.

## Observação sobre os dados

A base recente é recomendada para celular e reúne os arquivos mensais disponíveis desde junho de 2024. O histórico completo desde 2008 pode ser preparado pelo próprio aplicativo, mas exige mais processamento e armazenamento.

## Privacidade

Os dados usados são provenientes do Portal de Dados Abertos da PBH. A versão entregue não exige cadastro de usuários e não armazena consultas pessoais.
